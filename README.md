# Coffee Shop Sales Analysis

## Project Overview
This project analyzes coffee shop sales data to understand sales trends, popular products, and store performance.

## Dataset
Coffee Shop Sales dataset from Kaggle.

## Tools Used
- Python
- Pandas
- Matplotlib
- Plotly
- Streamlit

- requirements.txt
